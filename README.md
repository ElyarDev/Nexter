# 🏡 Nexter — Modern Real Estate Website

**Nexter** is a modern and responsive real estate website built with a strong focus on advanced CSS layouts, responsive design, and clean visual structure.

The project presents a fictional real estate platform where users can explore luxury properties, view featured houses, and discover professional real estate agents through a polished and modern interface.

🔗 **Live Demo:** [View Website](https://elyardev.github.io/Nexter/)

---

## ✨ Features

- 🏠 **Modern Real Estate UI** — Clean and professional property-focused design
- 🏡 **Property Showcase** — Display of featured houses and luxury properties
- 👨‍💼 **Real Estate Agents** — Dedicated section for featured agents
- ❤️ **Favorites UI** — Visual interaction for saving properties
- 📱 **Fully Responsive** — Optimized for different screen sizes
- 🎨 **Modern Visual Design** — Strong typography, spacing, and visual hierarchy
- 🖼️ **Property Gallery** — Image-focused property presentation
- ⚡ **Smooth Animations & Transitions** — Interactive visual effects
- 🧭 **Responsive Navigation** — Mobile-friendly navigation experience
- 📐 **Advanced CSS Layouts** — Grid-based page structure

## 📸 Website Sections

### 🏠 Hero Section

A visually engaging hero section that introduces the platform and highlights the luxury real estate experience.

### 🏡 Featured Properties

A collection of properties presented through modern cards, allowing users to quickly explore available houses.

### ❤️ Property Cards

Each property includes important information such as:

- Property name
- Location
- Price
- Number of rooms
- Property size

### 👨‍💼 Our Agents

A dedicated section introducing real estate agents and presenting their information in a clean card-based layout.

### 🏆 Customer Experience

Visual sections designed to communicate trust, quality, and the premium nature of the real estate service.

### 📱 Responsive Layout

The entire website adapts its layout and content to provide a consistent experience across mobile, tablet, and desktop devices.
